### technical notes
* this is a one take live recording. with mixing and mastering done in post.
* all audio recording are multi-tracked (4 stereo channel) via usb c from S-4 to my hackintosh (macos sequoia). recorded using ableton live 11.
* i set the buffer size to 256, which seems to be a sweet spot. i was using buffer size 128, but i was getting a lot of noise crackles/cpu drop out.
* ableton is sending midi clock to S-4 via usb, then from S-4 i send midi clock to Plinky via TRS 3.5mm. 
* i was sending midi clock to Plinky from ableton via usb, but it was not stable/very wonky. then i tried the TRS from S-4 which was very tight and a lot better.
* and also , i need the set the midi sync delay in ableton, i think its about -36ms.
* audio out from Plinky goes to S-4 analog in, and i put it into track 4.
