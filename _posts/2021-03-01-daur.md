it was started as a commisioned project for a fashion brand [Sejauh Mata Memandang,](https://sejauh.com/) what's interesting about this particular project, they using deadstock, unused fabrics, and recycle it to make new cloth.

the director, [Davy Linggar](https://www.instagram.com/davylinggar), had this idea to record all the sounds from the old factory that doing the recycle, and he requested that i must composed the music using all these sounds.

this was very exciting for me, and really enjoyed working on this project. i was really happy with the result, and the decided to release the tracks.
