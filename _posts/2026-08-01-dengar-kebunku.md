an exploration of torso [S-4](https://torsoelectronics.com/s4). this time i use kalimba sound as the main sound source, recorded directly to S-4 via grace felix amp. then i add ambient bird sound, recorded directly to S-4 mic, in front of my house.

---

i'm trying out a portable setup on this jam. using powerbank to power up S-4 and [zoom L6Max](https://zoomcorp.com/en/us/digital-mixer-multi-track-recorders/digital-mixer-recorder/livetrak-l6max/). it worked really well.

for powering S-4 i need this [dc to usb c cable](https://tk.tokopedia.com/ZS4hNrPNs/). specifically the one that provide 12v. and make sure it has positive center polarity.

for this to work need to use powerbank that has PD (Power Delivery) feature. for my case, it has to use to usb C port. the A-port only for 5V.

for powering zoom L6Max, since it require 5V, i xcan use any usb cable. i use usb c to A.
